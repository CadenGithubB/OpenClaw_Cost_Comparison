OpenClaw Cost Comparison

Compare the cost of your token volume, with the assumptions in view.

Start here: import an OpenClaw usage export, set the dates and pricing assumptions, choose the hosted models to compare, then add hardware costs. Add other model scenarios only when you want extra lines on the chart.

Runs offline

1. Import usage

Choose or drop a JSON export from OpenClaw Control UI → Usage, or paste it below. Up to 10 MB.

Supported export formats

Use an export containing aggregates.byModel, modelUsage, or sessions with usage.modelUsage. The sessions.usage Gateway response includes per-model aggregates. The gateway usage-cost summary alone does not.

Only token counts, model/provider names, dates, request counts and recorded costs are used. Phone numbers, session names, paths and other metadata are discarded from the report.

    4. Compare hardware costs

    Already-owned hardware excludes its past purchase price. Allocation applies to hardware and electricity; adjust it when other workloads share the machine. Use wall power attributable to this workload. Depreciation stops at the purchase price; replacement and resale are not assumed.

    Constant-usage projection

    Usage, selected rates and power stay constant. This is a scenario, not a forecast; promotional prices may expire. Hardware purchase and depreciation start at day zero.

    Other model scenarios

    Apply a different model’s rates to the same token volume. Add a scenario, then select Show in graph to draw its purple line. This does not predict equal output quality or the tokens it would use.
